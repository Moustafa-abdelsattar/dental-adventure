How to use this

Every line the game speaks, in the order it speaks it, screen by screen. Press ▶ to hear the exact clip that ships. The boxes under each line are editable — type a revised line and it is kept in your browser; Export edits downloads only what you changed, as JSON plus a ready-to-paste patch for en.json / ar.json, and a list of which clips would need regenerating.

Changing a line is not free. Narration is baked one clip per string per language. An English edit means re-running scripts/generate-audio-edge.mjs; an Arabic edit on a line marked recorded means booking the voice again.

Audio plays from app/public/audio/ next door, so open this file from inside the repo. Rebuild it with node scripts/build-narration-review.mjs; refresh the screenshots with node scripts/capture-narration-review.mjs.
