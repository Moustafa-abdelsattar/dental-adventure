# Dental Adventure v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the v1 of Dental Adventure — a bilingual (AR/EN), portrait, offline-capable PWA game that dentists send to parents so children aged 4–8 lose their fear before a dental visit.

**Architecture:** Single-page Vite + React + TypeScript app. A state-based screen router walks Language → Parent moment → Welcome → per-path modules (driven by JSON content manifests) → Reward. All copy lives in `en.json`/`ar.json` keyed by string id; every id has a pre-generated TTS clip per language. Milo is a layered SVG with a Motion state machine. Zustand store persisted to localStorage.

**Tech Stack:** Vite 7, React 19, TypeScript, Tailwind CSS 4 (`@tailwindcss/vite`), Motion (`motion` pkg, import from `motion/react`), zustand 5, vite-plugin-pwa, vitest + @testing-library/react + jsdom, Playwright, msedge-tts (audio generation script).

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-11-dental-adventure-v1-design.md` — every task implicitly inherits it.
- Portrait mobile-first; interactive content in lower ⅔ of screen; touch targets ≥ 2cm (min 72px CSS).
- Tap-first: every drag interaction must also work as tap-tap. No fail states — wrong tap = gentle wiggle + spoken hint.
- Star economy totals exactly **5 per path**; stars never reset; simulation always awards the final star.
- Copy rules: sensory words, never absolute promises ("never hurts", "no pain" are banned strings); AVOID list (no needles/blood/flash/harsh sounds/countdown pressure).
- All UI must work with `dir="rtl"`: use Tailwind logical utilities (`ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`) — never `ml-`/`left-` for layout that should mirror.
- Motion tokens verbatim: `soft {stiffness:180,damping:20}`, `playful {stiffness:350,damping:16}`, `snappy {stiffness:500,damping:28}`.
- Fonts bundled locally (no CDN): Baloo 2 (Latin), Baloo Bhaijaan 2 (Arabic).
- Premium-bar gate: at the end of Tasks 6, 7, 9–13, pause for a visual/motion review consulting the installed design skills (impeccable / emil-design-eng / frontend-design) before committing the polish pass.
- Commits: small, per task step as marked; message style `feat:`/`test:`/`chore:`.
- All commands run from repo root `F:\Dental_kids` with the app in `app/` subfolder.

```ts
import type { Lang, StringId } from './i18n'

const MUSIC_VOL = 0.25, DUCK_VOL = 0.08
class AudioController {
  private unlocked = false
  private current: HTMLAudioElement | null = null
  private music: HTMLAudioElement | null = null
  private last: { lang: Lang; id: StringId } | null = null
  private muted = false
  private talkingSubs = new Set<(talking: boolean) => void>()

  unlock() { this.unlocked = true }
  onTalkingChange(cb: (t: boolean) => void) { this.talkingSubs.add(cb); return () => this.talkingSubs.delete(cb) }
  private setTalking(t: boolean) { this.talkingSubs.forEach(cb => cb(t)) }

  say(lang: Lang, id: StringId): Promise<void> {
    if (!this.unlocked || this.muted) return Promise.resolve()
    this.current?.pause()
    const clip = new Audio(`/audio/${lang}/${id}.mp3`)
    this.current = clip; this.last = { lang, id }
    if (this.music) this.music.volume = DUCK_VOL
    this.setTalking(true)
    return new Promise(resolve => {
      clip.onended = () => { if (this.music) this.music.volume = MUSIC_VOL; this.setTalking(false); resolve() }
      clip.play().catch(() => { this.setTalking(false); resolve() })
    })
  }
  replayLast() { return this.last ? this.say(this.last.lang, this.last.id) : Promise.resolve() }
  startMusic() {
    if (!this.unlocked || this.music || this.muted) return
    this.music = new Audio('/audio/music.mp3')
    this.music.loop = true; this.music.volume = MUSIC_VOL
    void this.music.play().catch(() => {})
  }
  setMuted(m: boolean) { this.muted = m; if (m) { this.current?.pause(); this.music?.pause() } else this.music?.play() }
  _resetForTests() { this.unlocked = false; this.current = null; this.music = null; this.last = null; this.muted = false; this.talkingSubs.clear() }
}
export const audio = new AudioController()
```

```js
// npm i -D msedge-tts   (run from repo root)
import { MsEdgeTTS, OUTPUT_FORMAT } from 'msedge-tts'
import { readFileSync, mkdirSync, writeFileSync, existsSync } from 'node:fs'

const VOICES = { en: 'en-US-AnaNeural', ar: 'ar-EG-SalmaNeural' }
for (const lang of ['en', 'ar']) {
  const strings = JSON.parse(readFileSync(`app/src/content/strings/${lang}.json`, 'utf8'))
  const vocative = strings['friend.vocative']
  mkdirSync(`app/public/audio/${lang}`, { recursive: true })
  const tts = new MsEdgeTTS()
  await tts.setMetadata(VOICES[lang], OUTPUT_FORMAT.AUDIO_24KHZ_96KBITRATE_MONO_MP3)
  for (const [id, template] of Object.entries(strings)) {
    const out = `app/public/audio/${lang}/${id}.mp3`
    if (existsSync(out)) continue
    const text = template.replaceAll('{name}', vocative)
    const { audioStream } = await tts.toStream(text, { rate: '-10%' })
    const chunks = []
    for await (const c of audioStream) chunks.push(c)
    writeFileSync(out, Buffer.concat(chunks))
    console.log('✓', lang, id)
  }
}
```
