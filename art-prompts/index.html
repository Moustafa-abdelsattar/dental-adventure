🦷 Dental Adventure — Art Prompt Sheet

How to use (per card):
  1. In ChatGPT (image generation), attach the reference image shown on the card (they're in the ref/ folder next to this file).
  2. Paste the prompt (Copy button) and generate. Ask for a re-roll if the style drifts from the reference.
  3. Save the result with the exact filename on the card into F:\Dental_kids\art-in\.
  4. When the folder is ready, tell Claude "art is in" — everything gets wired in and animated.
Rules that keep the set consistent: always attach the same reference, always keep the STYLE paragraph unchanged, always request transparent background PNG, 1024×1024, single centered subject. If ChatGPT can't do transparency, ask for a plain solid #FEF9F0 background instead.
